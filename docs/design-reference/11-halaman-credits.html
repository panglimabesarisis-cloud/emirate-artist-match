Token rates

Cost follows the standard way model providers bill: tokens in, tokens cached, tokens out, each at a price per 1,000,000 tokens.

ModelInputCachedOutput
cost = (input x in + cached x cache + output x out) / 1,000,000

Rates are USD per 1M tokens. Reasoning tokens count as output. Long prompts can cost more at some providers. Figures here are estimates, the provider invoice is the final number.

How credits work

  • One reply, one credit. A short answer and a long quote draft both cost 1 credit.
  • Tokens show the real work. Input is what the AI read, output is what it wrote. Cached input is cheaper because it was read before.
  • Nothing is hidden. Each row in your history keeps the rates that applied that day, so old rows never change.
  • Out of credits? Replies pause and chats go to you. Top up and the agent resumes.
